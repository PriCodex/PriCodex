## Current Direction

I am building a connected learning stack across:

1. mathematical foundations for machine learning
2. deep learning architectures
3. transformer and LLM internals
4. reinforcement learning
5. data science practice and evaluation

The goal is to move from reading to implementation to reproducible experiments, with each repository acting as a durable learning and research artifact.

## Working Style

- Start with foundations before abstractions.
- Prefer runnable examples over passive notes.
- Treat evaluation, leakage, and reproducibility as first-class topics.
- Write explanations that are useful for future review, not only for the current session.
- Build small complete systems before scaling to larger ones.
